# 德州扑克 · 娱乐学习版（单机 + 联机 + 自动对账）

纯娱乐虚拟筹码，不涉及真钱。No-Limit 德州扑克，4 人桌，支持 AI 陪练与好友房间联机。

## 功能

- **单机练习**：你 vs 3 个 AI，启发式策略，可随时开新一手。
- **好友联机**：创建房间生成 4 位房间码 / 邀请链接，好友加入同桌；空位可添加 AI 补位。服务端权威发牌与结算，前端只投影公开信息（他人底牌默认隐藏）。
- **完整规则**：翻牌前 / 翻牌 / 转牌 / 河牌四轮下注；弃牌、过牌、跟注、加注、全下；小盲 / 大盲；最小加注额记账。
- **主池 / 边池**：按各玩家投入额分层建池，全下玩家只能赢自己有资格的池；弃牌死钱留在所达池内。
- **机器对账**：每手结束自动校验并在面板展示：
  1. 筹码守恒（开局 = 结束）
  2. 底池清零
  3. 牌面唯一（无重复牌）
  4. 派彩资格与牌型（赢家均有资格且为该池最大）
  5. 派彩金额闭合（无空池）
  - 可一键导出对账账本 JSON（追加式事件日志）。

## 目录结构

```
poker/
├── server.js            # 静态托管 + WebSocket 房间服务（权威调度）
├── src/poker-core.js    # 纯逻辑引擎：评估 / 状态机 / 边池 / 对账（浏览器与 Node 共用）
├── public/index.html    # 前端页面（菜单、牌桌、操作栏、对账面板）
├── test/core.test.cjs   # 引擎单元 + 边池 + 500 手随机压测
└── test/online.test.cjs # 联机集成测试（双客户端走一手并校验对账）
```

## 本地运行

```bash
npm install
npm start          # 默认 http://localhost:3000 ，可用 PORT=xxxx 改端口
```

- 单机：打开页面 → 填昵称 →「单机练习」。
- 联机：一方「创建房间」，把房间码或邀请链接发给好友；好友打开链接 / 填码「加入房间」。人齐后点「开始新的一手」，不足 2 人会自动补 AI。

## 测试

```bash
npm test                 # 引擎单元 + 边池 + 500 手守恒压测
node test/online.test.cjs # 联机双客户端集成测试（自动起服务端）
```

## 部署给好友公网访问

本项目是 Node 服务（HTTP + WebSocket），需部署到支持长连接的环境：

- 自己的 VPS：`npm install && npm start`，用 Nginx/Caddy 反代并放行 WebSocket；
- 或 Railway / Render / Fly.io 等 PaaS，启动命令 `node server.js`，端口读环境变量 `PORT`。

> Cloudflare 静态托管只能跑纯前端，不能主持 WebSocket 房间；联机房间需放在上述 Node 服务环境。

## 规则与简化说明

- 牌型：高牌 < 一对 < 两对 < 三条 < 顺子 < 同花 < 葫芦 < 四条 < 同花顺。
- 短全下（不足最小加注）不重新开放行动；不考虑前注（ante）、straddle、跑两次、奥马哈等变体。
- 对账为本地/服务端自检，用于学习核对筹码与派彩，不代表任何真实博彩结算。
